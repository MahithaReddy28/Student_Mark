# Student Grade Calculator

## Project Description
The Student Grade Calculator is a simple Python application that calculates a student's total marks, average, grade and pass/fail result based on the marks entered.

## Features
- Accepts student name and five subject marks.
- Calculates total and average marks.
- Determines the student's grade.
- Displays pass or fail status.
- Checks for invalid marks.

## Technologies Used
- Python 3

## Concepts Used
- Variables and data types
- User input and output
- Arithmetic operators
- Conditional statements

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python student_grade_calculator.py
```
